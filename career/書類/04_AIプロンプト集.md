# AIプロンプト集（志望動機・自己PR・職務経歴書・面接）

使い方：下のプロンプトをClaude等に貼り、【 】に `01_ヒアリングシート.md` の答えと求人票を入れる。
**出てきた文章は必ず自分で読み直し、言っていないこと・盛った数字があれば消す。**

---

## 1. 職務経歴書を作る

```
あなたは日本の転職市場に詳しいキャリアアドバイザーです。
下の【ヒアリング内容】から、職務経歴書を作ってください。

条件：
- 構成：職務要約（3〜5行）／活かせる経験・スキル（3〜5個）／職務経歴（会社ごとに表）／業務外の取り組み／資格／自己PR（300〜400字）
- 実績は必ず数字で書く。ヒアリングにない数字は作らず、【要確認：〇〇の数字】と書く
- 顧客の実名・社外秘の金額は書かない
- 応募職種【職種名】に関係する経験を先に、関係の薄いものは短く
- A4で2枚以内に収まる分量

【ヒアリング内容】
（ここに貼る）
```

## 2. 志望動機を作る（応募先ごと）

```
下の【私の経歴】と【求人票】をもとに、履歴書に書く志望動機を作ってください。

手順：
1. 求人票から「この会社が求めている人物像」を3つ抜き出す
2. 私の経歴の中から、それぞれに当てはまる経験を1つずつ探す（無理に当てはめない）
3. 次の構成で250〜300字にまとめる：
   ① なぜこの業界・職種か（自分の経験から来るきっかけ）
   ② なぜこの会社か（サービス・事業の具体的な点を1つ。他社でも言える内容は不可）
   ③ 自分の経験をどう活かして、何に貢献するか
4. 同じ構成で、言い回しを変えた案を3つ出す
5. 最後に「この志望動機に面接官がしそうな深掘り質問」を3つ挙げる

ルール：私の経歴にないことは書かない。「御社でなければ」の理由が弱い場合は、調べるべき点を教えて。

【私の経歴】
（職務要約と工夫したエピソードを貼る）

【求人票】
（会社名、事業内容、仕事内容、求める人物像をそのまま貼る）

【その会社に惹かれた点（自分のメモ）】
（ここに書く）
```

## 3. 自己PRを応募先に合わせて書き換える

```
下の【自己PR（土台）】を、【求人票】の求める人物像に合わせて書き換えてください。
- 強みとエピソードは変えず、「応募先でどう活かすか」の部分と、言葉選び（求人票の言葉を使う）だけ変える
- 300〜400字
- 書き換えた箇所が分かるように、変更点を最後に箇条書きで示す

【自己PR（土台）】
【求人票】
```

## 4. 書類を添削してもらう

```
あなたは中途採用を年間100名以上担当してきた採用担当者です。
下の【書類】を、【応募職種】の書類選考をする立場で読んで、次の形式で評価してください。
- 会ってみたいと思うか（5段階）とその理由
- 良い点を3つ
- 落とされる原因になりそうな点を3つ（具体的に、どの文をどう直すか）
- 数字や根拠が足りない箇所
- 面接で必ず聞かれそうな質問を5つ

【応募職種】
【書類】
```

## 5. 面接の想定問答

```
下の【書類】と【求人票】をもとに、一次面接の想定質問を10個と、
私の経歴に沿った回答例（各1分＝300字程度で話せる量）を作ってください。
必ず入れる質問：自己紹介／転職理由／志望動機／一番の実績／失敗経験／なぜ営業職以外も考えているか（または、なぜこの職種か）／逆質問
転職理由は、前の会社の不満ではなく「次にやりたいこと」の言い方にする。

【書類】
【求人票】
```

---

## AIを使うときの注意
- 個人情報（住所・電話・生年月日）はAIに入れなくていい。書類に入れる段階で自分で書き足す
- 現職の顧客名・社外秘情報は入れない
- AIが作った文は、きれいすぎて「誰でも書ける文」になりがち。**自分しか書けない具体的な数字と場面**を1つ必ず残す
