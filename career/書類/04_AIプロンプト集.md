# AIプロンプト集（見直し・リサーチ専用）

サラタメさんの方針に合わせ、**AIは「書かせる」のではなく「調べる・見直す」ために使う。**
（AIに書かせると経験していない話が混ざり、自分の言葉でなくなって面接台本にならないため）

①〜③はサラタメさん配布の「AIプロンプト集」と同じ目的のもの。原文は公式LINE特典のGoogleドキュメントにある。
ここには、その考え方に沿って、志望動機・面接まで広げた版を置く。

## 使う前に必ず
- ChatGPT・Gemini は「一時チャット」、Claude は「シークレットモード」で使う
- **氏名・会社名・住所・電話・メール・顔写真を消してから**渡す（会社名は「A社」などに置き換え）
- 指摘は全部鵜呑みにしない。致命的なミスだけ直し、どうしても伝えたい点は残す
- 最後は**一晩寝かせて翌日の自分が読む**

---

## ① 履歴書の見直し
```
添付の履歴書を添削してください。
確認すること：誤字脱字／文法・不自然な表現／表記ゆれ／年月・数字・記号・スペースの全角・半角の混在／簡潔さと敬語。
英数字・記号は原則半角にそろえ、日本語として全角が自然な句読点などは変えないでください。
経歴や事実を推測して足したり変えたりせず、足りない情報は「不足」として指摘してください。
出力：1. 修正箇所の表（該当箇所／修正前／修正後／理由） 2. 修正後の全文
```

## ② 企業リサーチ（求める人物像）
```
【業界】の【企業名】が募集している【職種・ポジション】への転職を考えています。
募集要項、採用サイト、公式サイト、社員インタビュー、公式YouTube・note、IR・経営方針など、
企業が公式に出している新しい情報を優先して調べ、このポジションで求められる人物像を分析してください。
各項目に根拠となる情報源を付け、「公式情報で確認できる事実」と「そこからの推測」を分けて書いてください。
最後に、転職エージェントや面接で確認すべき「裏の情報」の質問を5つ挙げてください
（今なにに困って採用しているか、活躍している人の特徴、通りやすい書類 など）。
```

## ③ 職務経歴書の見直し（応募先に合わせて）
```
添付の職務経歴書を、添付の応募先情報（求める人物像）を踏まえて添削してください。
確認すること：
1. 読みやすさ：誤字脱字・表記ゆれ・全角半角／社内用語が社外の人にも分かるか／見出しと箇条書きの階層が整理されているか
2. 実績と再現性：実績が数字・達成率・順位・前年比で具体的か／結果だけでなく課題→工夫→行動→結果のプロセスがあるか
3. 応募先との一致：必須要件・求める人物像に合う経験が強調されているか／職務要約・職務経歴・自己PRに一貫性があるか／資格・スキルが関係あるものか
事実や実績を推測・誇張・創作しないでください。足りない数字や情報は勝手に補わず、確認事項として指摘してください。
AIっぽい文章にせず、本人が面接で説明できる自然な表現にしてください。
出力：1. 3項目の評価 2. 修正箇所の表（該当箇所／修正前／修正後／理由） 3. 実績を具体化するための質問 4. 修正後の全文
```

## ④ 志望動機の見直し（自分で書いた下書きを渡す）
```
添付の志望動機（自分で書いた下書き）と、応募先の情報を読んで、見直してください。
確認すること：
- 「なぜこの業界・職種か」「なぜこの会社か」「自分の経験をどう活かすか」の3つがそろっているか
- 「なぜこの会社か」が、社名を他社に変えても通じる内容になっていないか
- 職務経歴書の自己PR・実績と矛盾していないか
- 前の会社の不満が透けて見えないか
私の経歴にないことは足さないでください。弱い部分は、私が調べる・考えるべきことを質問の形で示してください。
出力：1. 良い点 2. 弱い点と直し方 3. 面接官がしそうな深掘り質問3つ 4. 最小限の修正を入れた全文（250〜300字）
```

## ⑤ 採用担当の目で読んでもらう（最終チェック）
```
あなたは中途採用で年間1,000通以上の書類を見る採用担当者です。
添付の職務経歴書を【応募職種】の書類選考として、最初の10秒で読む範囲（職務要約と各見出し）だけ見た印象と、
全文を読んだあとの印象を分けて教えてください。
- 10秒で「会ってみたい」と思うか、その理由
- 落とされる原因になりそうな点を3つ
- 面接で必ず深掘りしたくなる点を3つ（＝面接台本として機能しているか）
文章の書き換えはせず、指摘だけにしてください。
```

## ⑥ 面接の想定問答（書類が固まってから）
```
添付の職務経歴書と応募先情報をもとに、一次面接の想定質問を10個出してください。
必ず含める：自己紹介／転職理由／志望動機／一番の実績の深掘り（STARで）／失敗経験／なぜこの職種か／逆質問。
回答例は作らず、それぞれの質問について「答えるときに必ず入れるべき要素」と「書類のどの部分を根拠にするか」だけ示してください。
回答は自分の言葉で準備します。
```
