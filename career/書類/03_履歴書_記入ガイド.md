# 履歴書 記入ガイド

履歴書のゴールは「**無駄に減点されず、本編の職務経歴書まで読んでもらう**」こと。
ミスなく・空欄なく・職務経歴書と矛盾なく。

## フォームと写真
- 厚生労働省の履歴書様式例（性別欄が任意のもの）かJIS規格をダウンロードし、パソコンで作成 → PDF
- 写真：スマホの証明写真アプリは使わない
  - 身だしなみを自分で整えられる → スピード写真（1,000〜2,000円）
  - 自信がない → フォトスタジオ（7,000〜10,000円）
  - NG：暗い／アゴが上がっている／表情が硬い／服がヨレヨレ

## 欄ごとの書き方

| 欄 | 書き方 | よくあるミス |
|---|---|---|
| 日付 | 提出日。西暦か和暦にそろえる | 作成日のまま |
| 連絡先 | 個人の携帯・個人のメール | 会社のメール |
| 学歴 | 高校入学から。正式名称（「〇〇県立〇〇高等学校」） | 「高校」と略す |
| 職歴 | 会社名は正式名称。入社／退職を1行ずつ。退職は「一身上の都合により退職」。在職中は最後に「現在に至る」、次の行の右に「以上」 | （株）と略す |
| 免許・資格 | 取得順・正式名称・取得年月 | 「普通免許」（正：普通自動車第一種運転免許） |
| 備考欄 | **短期離職・空白期間があれば先回りして説明**（下の例）。なければ在職中である旨と面接可能な時間帯 | 気になる経歴を放置 |

**表記**：数字・英字は**半角**にそろえる。カッコは全角・半角どちらかに統一。

## 職歴欄の例（在職中）
```
2018  4  株式会社〇〇 入社
2022  4  営業部 リーダーに昇格
         現在に至る
                                                     以上
```

## 備考欄の例

**短期離職・空白期間がない場合**
```
現在在職中のため、平日19時以降または土日に面接日程をご調整いただけますと幸いです。
入社可能時期：内定後2か月程度
```

**短期離職・空白期間がある場合**（構成：何があったか → やむを得なかった理由 → **今は解決していて継続して働ける**）
```
■〇〇株式会社を短期間で退職した理由
入社後、【事実】のため、【調整・検討したこと】をしましたが、【やむを得なかった理由】により退職いたしました。
現在は【解決している状況】であり、継続して就業できる環境が整っております。
```
- 一番納得されやすいのは家庭の事情。スキルアップ・体調不良は懸念を持たれやすいので、「今は問題ない」根拠を具体的に
- **事実だけを書く**。盛った理由は面接で深掘りされると崩れる
