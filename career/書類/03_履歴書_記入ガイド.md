# 履歴書 記入ガイド

履歴書は「形式の書類」、中身で勝負するのは職務経歴書。**ミスなく・空欄なく・職務経歴書と矛盾なく**が目標。

## フォーム
- 厚生労働省の履歴書様式例（性別欄が任意記載のもの）か、JIS規格のものをダウンロードしてパソコンで作成 → PDF
- 指定がない限り手書きは不要
- 写真：3か月以内・スーツ・明るい背景。データで貼る

## 欄ごとの書き方

| 欄 | 書き方 | よくあるミス |
|---|---|---|
| 日付 | 提出日（郵送なら投函日）。西暦か和暦にそろえる | 作成日のまま放置 |
| 連絡先 | 個人の携帯・個人のメール | 会社のメールを書く |
| 学歴 | 高校卒業から。学校名は正式名称（「〇〇県立」「高等学校」） | 「高校」と略す |
| 職歴 | 会社名は正式名称（株式会社の位置も）。入社・異動・退社を1行ずつ。在職中は最後に「現在に至る」、その下の行に右寄せで「以上」 | 「株式会社」を（株）と略す |
| 免許・資格 | 取得順に正式名称。勉強中のものは「〇〇取得に向けて勉強中」も可 | 「普通免許」と略す（正：普通自動車第一種運転免許） |
| 志望動機 | 200〜300字。職務経歴書の自己PRと同じ強みを使い、「なぜこの会社か」を1文入れる → `04_AIプロンプト集.md` | どの会社にも出せる文章 |
| 本人希望欄 | 基本は「貴社規定に従います。」。在職中の場合：「現在在職中のため、平日19時以降または土日に面接日程をご調整いただけますと幸いです。入社可能時期：内定後2か月程度」 | 給与などの条件を細かく書く |

## 職歴欄の例（在職中）
```
2018  4  株式会社〇〇 入社
         営業部に配属。中小企業向けITサービスの新規開拓営業に従事
2022  4  営業部 第二グループ リーダーに昇格
         現在に至る
                                                     以上
```
