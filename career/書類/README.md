# 転職書類セット（どこに出しても通用する版）

在職中の転職活動用。「1回しっかり作った土台」を、応募先ごとに少しだけ書き換えて使い回す設計です。

> 参考動画：「転職の『志望動機』、もうAIでつくれちゃうわ…。」（転職のサラタメさん／https://youtu.be/rOzSxiMRN2o）
> 確認できたのはタイトルとチャンネル名だけで、動画の中身は読めていません（YouTubeのbot確認で取得不可）。
> このフォルダは一般的な書類作成の知識をもとにしており、動画のテーマ「AIで志望動機を作る」に合わせて、プロンプト集を付けています。
> 文字起こしを貼ってもらえれば、動画の主張と突き合わせて直します。

## 使う順番

| 順 | ファイル | やること | 誰が |
|---|---|---|---|
| 1 | `01_ヒアリングシート.md` | 質問に箇条書きで答える（ここが全部の材料） | あなた（60〜90分） |
| 2 | `02_職務経歴書_テンプレート.md` | 1の答えから職務経歴書を作る | AI → あなたが確認 |
| 3 | `03_履歴書_記入ガイド.md` | 市販・ダウンロードの履歴書フォームに書き写す | あなた |
| 4 | `04_AIプロンプト集.md` | 応募先ごとに志望動機・自己PRを作り分ける | AI → あなたが確認 |

## 全部の書類に共通する5つのルール

1. **数字で書く**：「頑張った」ではなく「達成率120%・社内3位」。数字がない実績は、件数・期間・人数・前後比較に置き換える
2. **結論から書く**：各項目の1行目だけ読めば分かるようにする。採用担当が1通にかける時間は短い
3. **応募先の言葉に合わせる**：求人票に出てくる言葉（例：「インサイドセールス」「顧客折衝」「AI活用」）を、自分の経験の説明に使う
4. **3つの書類で話をそろえる**：履歴書・職務経歴書・面接で言うことが矛盾しないようにする
5. **AIの文章はそのまま出さない**：AIは「たたき台を作る係」。最後は自分の言葉に直す。**事実でないこと・盛った数字は絶対に入れない**（面接で深掘りされて崩れる）

## 提出前チェックリスト

- [ ] 誤字脱字、日付（提出日・西暦／和暦の統一）
- [ ] 実績の数字が3つ以上入っている
- [ ] 職務経歴書の冒頭「職務要約」が3〜5行で、読むだけで何ができる人か分かる
- [ ] 志望動機に「その会社でなければならない理由」が1つ入っている（社名を変えても通じる文章になっていない）
- [ ] 現職の社外秘（顧客名・具体的な売上額など）を書いていない。顧客名は「大手通信会社」のようにぼかす
- [ ] ファイル名：`職務経歴書_氏名_20261117.pdf` のように日付と氏名入り、PDFで提出
- [ ] 在職中なので、連絡先は個人のメール・携帯。面接可能な時間帯（平日19時以降・土日 など）を書いておく
