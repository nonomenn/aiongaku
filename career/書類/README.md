# 転職書類セット（どこに出しても通用する版）

在職中の転職活動用。「1回しっかり作った土台」を、応募先ごとに少しだけ書き換えて使い回す。
土台の考え方は、転職のサラタメさんの「応募書類完全ガイド」（公式LINE特典）に合わせている → `00_動画まとめ_応募書類完全ガイド.md`

## 使う順番（ガイドの4ステップに対応）

| 順 | ファイル | やること | 誰が |
|---|---|---|---|
| 0 | `00_動画まとめ_応募書類完全ガイド.md` | 考え方を読む（10分） | あなた |
| 1 | `01_棚卸しメモ.md` | STEP① 自由にメモで吐き出す | **あなた**（60〜90分） |
| 2 | `04_AIプロンプト集.md` の②と⑥ | STEP② 応募先の求める人物像を調べる | AI＋エージェントに聞く |
| 3 | `02_職務経歴書_テンプレート.md` | STEP③ 要約 → 経歴 → 自己PR → 資格の順に埋める | **あなた**（迷ったら私が構成を手伝う） |
| 4 | `03_履歴書_記入ガイド.md` | 履歴書を書く | あなた |
| 5 | `04_AIプロンプト集.md` の①③④⑤ | STEP④ AIに見直させる → **翌日の自分**が読む | AI → あなた |

## 全部の書類に共通するルール

1. **10秒で読める**：各項目の1行目と職務要約だけで「何ができる人か」が分かる
2. **数字・比較・プロセス**：「達成」ではなく「目標120件に対し126件（105%）・店舗8名中1位」。結果だけでなく、どう工夫したか（STAR）
3. **応募先に合わせる**：求人票の必須要件に近い経験を前に・厚く
4. **面接の台本として書く**：深掘りしてほしい話を厚く書く。書類と面接で話を一致させる
5. **AIは見直し専用**：AIに書かせると経験していない話が混ざる。**事実でないこと・盛った数字は絶対に入れない**
6. **AIに渡すときは**シークレットモード／一時チャットで、氏名・会社名・住所・電話・メール・顔写真を消してから

## 提出前チェックリスト

- [ ] 誤字脱字、**数字・英字は半角**、表記ゆれ（西暦／和暦、「％」と「%」など）
- [ ] 職務要約が ✔ 3〜5行で、一番刺さる数字が入っている
- [ ] 実績に「比較」が入っている（目標比・順位・前年比・平均比）
- [ ] 取り組みと成果が STAR（状況→課題→取り組み→結果）になっている
- [ ] 社内用語・略語を、社外の人が分かる言葉に直した
- [ ] 求人票の必須要件に対応する経験が、上のほうに書いてある
- [ ] 3〜4ページ以内。フォントは1種類
- [ ] 顧客名・社外秘の数字をぼかした（例：「大手通信キャリア」）
- [ ] 一晩寝かせて、翌日にもう一度読んだ
- [ ] PDFで提出。ファイル名は `職務経歴書_氏名_20261117.pdf` のように
- [ ] 在職中なので連絡先は個人の携帯・メール。面接可能な時間帯を書いた
