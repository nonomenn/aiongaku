# まとめ：サラタメ式「応募書類完全ガイド」

出典：転職のサラタメさん 公式LINE特典のGoogleドライブ「【サラタメ式】応募書類完全ガイド」
（まとめテキスト資料・履歴書見本・職務経歴書見本・AIプロンプト集・棚卸しメモ）を読んで要約。
※動画「転職の『志望動機』、もうAIでつくれちゃうわ…。」（https://youtu.be/rOzSxiMRN2o）の本編はYouTube側の制限で読めていない。下は資料の内容。

---

## 30秒版

- **落ちる人は10秒で落とされる**：採用側にとって自分の1枚は「1,000枚のうちの1枚」
- **書類通過がゴールではない**：職務経歴書は面接の台本。聞いてほしいことを厚く書き、聞かれたくないことには触れない
- **重要度は 履歴書 ≪ 職務経歴書**
  - 履歴書 ＝「減点されない」ための書類
  - 職務経歴書 ＝「再現性を証明する」ための書類（前の会社で活躍した → うちでも活躍できそう、と思わせる）
- **AIは「書かせる」のではなく「見直させる」**。最後は翌日の自分が読み直す

## 第1章 履歴書：減点されないこと

### ダメ① 単純なミスの放置
| ミス | 対策 |
|---|---|
| 誤字脱字 | AIに添削させる |
| 全角・半角のバラつき | **数字・英字は半角**にそろえる。カッコは全角・半角どちらでも統一すればOK |
| 写真が微妙（暗い・アゴが上がる・表情が硬い・服がヨレヨレ） | スマホの証明写真アプリは使わない。身だしなみを自分で整えられるならスピード写真（1,000〜2,000円）、自信がなければフォトスタジオ（7,000〜10,000円） |

AIに見せるときは、**シークレットモード／一時チャット**を使い、**氏名・会社名・住所・電話・メール・顔写真を消してから**渡す。

### ダメ② 「キャリア爆弾」（短期離職・空白期間）の放置
- 放置すると職務経歴書すら読まれずに落ちる
- **備考欄で先回りして説明する**：「懸念されるのは分かっている。でも心配いらない」と伝える
- 理由のタイプ別の伝わり方

| 評価 | タイプ | ポイント |
|---|---|---|
| ◎ | 家庭の事情（介護・子育て・家業） | 「仕方ない」と納得されやすく、深掘りもされにくい。「今は解決済み」まで書く |
| ○ | 仕事以外の実績（スポーツなど） | 第二新卒など若手でないと使いにくい |
| ○ | ミスマッチ（入社前の説明と違った等） | 書き方次第で他責に見える。残業・休日など働き方に触れると特に警戒される |
| △ | 起業・フリーランスから戻る | 実力はありそうに見えるが「また独立するのでは」と思われる |
| × | スキルアップ（資格勉強・スクール） | 「辞めなくても両立できたのでは」と思われる |
| × | 体調不良 | 「再発しないか」の不安を生む |

※資料では「家庭の事情を膨らませて書く人もいる（推奨はしない）」とも触れているが、**事実でないことは書かない**。面接で崩れるし、入社後も苦しくなる。

## 第2章 職務経歴書：再現性を証明する

### 4つの項目
1. **職務要約**（いちばん大事。YouTubeのサムネと同じ「つかみ」）
2. **職務経歴**（会社概要／職務内容／取り組みと成果／実績・表彰）
3. **資格・スキル**（重要度は低い）
4. **自己PR**

形式は自由（企業から指定されることはほぼない）。フォントは見やすい標準的なもの1種類で統一。**基本3〜4ページ以内**。

### やりがちなダメパターン3つ
1. **読みにくい**
   - 社内用語・略語を使う（例：「NP」→「個人売上目標」、「SS」→「副店長」）
   - 箇条書きの階層がぐちゃぐちゃ
   - 変わったフォント、フォントの混在
2. **無味無臭**
   - 数字がない（×「目標達成」 ○「個人目標105%達成」）
   - 比較がない（×「4棟販売」 ○「目標2棟に対し4棟・21名中1位」）
   - 再現性がない：結果だけ並べると「会社や環境のおかげでは？」と思われる → **プロセスを書く**
   - ⚠ ただし盛りすぎ・捏造は絶対NG（面接でバレる。入社後にギャップで苦しむ）
3. **応募条件とズレている**
   - 例：SaaSのインサイドセールスで必須要件が「新規開拓経験」なのに、ルート営業の話ばかり → 少しでも新規開拓の要素があれば厚く書く
   - 長すぎる（5〜6ページ）＝相手が何を求めているか絞り切れていない

### 作り方4ステップ

**STEP① ザックリ棚卸し**
- いきなり職務経歴書の形式に書かない。まず自由にメモで吐き出す
- 必須：時系列／所属（会社・部署）／仕事内容
- できれば：実績（数字）／プロセス（工夫したこと）／身についた力

**STEP② 企業リサーチ（裏の情報まで）**
- レベル1：業界・職種の傾向をつかむ（例：コンサルは基本ロジカル・高学歴重視。その中で「コミュ力重視の会社」という例外を見つけたら狙い目）
- レベル2：個別企業
  - 表の情報：募集要項（抽象的）／**社員インタビュー（出てくる人＝求める人物像）**／AIで調査
  - 裏の情報：今なにに困って採用しているか、どんな人が活躍しているか、どんな書類が通るか
    - 口コミサイト（OpenWork・転職会議・キャリコネ・Indeed）※退職者のネガティブな声に偏る
    - **転職エージェント**：面接官・合格者・不合格者の全員と接点があるので一番知っている。遠慮なく聞く（ただし担当の当たり外れは大きい）
- 会社のタイプで見せ方を変える：個人成果重視なら行動力、チーム重視なら調整力・巻き込み力

**STEP③ 面接をイメージして項目を埋める**（書く順番も大事）
1. **職務要約から書く**：在籍企業・配属・職種／具体的な業務／一番刺さる実績の数字。**箇条書き（✔）で3〜5行**
2. **職務経歴**：基本は新しい順（見せたい経験が古いなら古い順でもOK）
   - 会社概要（社名・在籍期間・事業内容・資本金・従業員数）
   - 職務内容
   - **取り組みと成果をSTAR法で**（ここで差がつく）
     - Situation 状況 → Task 課題 → Action 取り組み → Result 結果
   - 実績（数字・表彰）
3. **自己PR**（資格欄より先に書く。重要度が高い）
   - 「〇〇力」を2〜3個。**修飾語を付ける**（例：潜在ニーズを引き出す「傾聴力」／徹底した事前準備による「商談推進力」／成果から逆算した「巻き込み力」）
   - 本文の型：**結論 → 理由（エピソード）→ 御社でもこう活かせる**
4. **資格・スキル**：見本どおりでOK。関係ないものは省く

**実績で悩んだとき**
| 悩み | 対処 |
|---|---|
| ずっと目標未達 | 比較対象を変える：部署平均より上／部署で何位／同期で何位／前任者比／前年比。それも無理ならプロセスで勝負 |
| 数字で書ける実績がない | 会社のKPI以外の数字を探す：架電数、顧客満足度、PV数、声かけ数、欠品率など |
| 守秘義務 | 顧客名・社外秘の数字はぼかす（例：ドコモ → 大手通信キャリア） |
| チームの実績を書いていい？ | 書いてOK。面接では自分の成果と分けて話す |

**STEP④ AIと翌日の自分に見直させる**
- AIは見直し専用。理由：①経験していない話を混ぜる（文章がうまいので気付きにくい） ②自分の言葉でなくなり、面接台本にならない
- AIの指摘も全部は鵜呑みにしない。致命的なミスだけ直し、「どうしても伝えたい点」は残してよい
- **一晩寝かせて翌日の自分が読む**（AIより大事）。初見の採用担当に近い目で見られる

## 見本から分かる「形」

**職務経歴書見本**（営業・2社経験）の構成
```
職務経歴書　　　　　　　　　　　　　　　　2026年6月27日現在　氏名
■ 職務要約　✔×5行（会社・昇格・実績の数字・表彰）
■ 職務経歴
  【会社概要】企業名／在籍期間（〇年〇か月）／事業内容／資本金／従業員数
  期間｜配属
    ＜職務内容＞ ①② で大きく分け、・で中身
    ＜取り組みと成果＞ 見出し1行（例：売上目標200%達成 → 目標2棟/実績4棟・21名中1位）
       状況／課題／取り組み／結果（すべて数字入り：月1件→月3件、10%→55% など）
    ＜実績＞ 期ごとの達成率（目標/実績）
    ＜表彰＞
  （前職も同じ形で、少し短く）
■ 資格・スキル　＜資格＞取得年月つき／＜スキル＞Office・Salesforce等
■ 自己PR　「修飾語＋〇〇力」×3、それぞれ 結論→エピソード（数字）→次の仕事での活かし方
以上
```

**履歴書見本**：学歴は高校入学から／職歴は「一身上の都合により退職」／資格は正式名称・取得年月／**備考欄で短期離職の理由と「現在は解決済み」を説明**。
