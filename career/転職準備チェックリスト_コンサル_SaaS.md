# 転職準備チェックリスト（コンサル・SaaS業界）

> この版は**一般的な転職準備の知識**をもとにした下書きです。参考動画（https://youtu.be/KboWw0zQ78w）の中身はまだ読めていません。
> 文字起こしが手に入ったら、動画の主張と突き合わせて直します。

前提：営業経験あり。在宅寄りの働き方も視野。整体院向け事業（`seitai/`）と並行する可能性あり。

---

## 0. 先に決めること（1週目）

- [ ] **どちらを狙うか**：SaaS（入りやすく、営業経験がそのまま活きる）／コンサル（年収の伸びは大きいが、選考対策が重い）
- [ ] **職種**
  - SaaS：インサイドセールス（IS）・フィールドセールス（FS）・カスタマーサクセス（CS）
  - コンサル：IT・DX系、業務改善系、営業・マーケ支援系
- [ ] **条件の優先順位**：年収／在宅（フルリモートか週何日か）／副業OKか（整体院の事業を続けるなら最重要）／勤務地
- [ ] **期間の目安**：応募から内定までおおむね2〜3か月。退職の申し出（就業規則で多くは1か月前）も逆算に入れる

## 1. 自分の棚卸し（1〜2週目）

- [ ] これまでの営業経験を**数字で**書き出す：達成率、売上・件数、順位、架電数・商談数・受注率、扱った商材と顧客層
- [ ] 「工夫したこと → 結果」の具体例を3つ（面接でそのまま話す材料になる）
- [ ] 辞めたい理由を「次にやりたいこと」の言い方に直しておく
- [ ] **なぜSaaS／なぜコンサルか**を自分の経験とつなげて一言で言えるようにする

## 2. 書類（2週目）

- [ ] 履歴書
- [ ] **職務経歴書**（いちばん大事）：冒頭に要約3行 → 実績を数字で → 活かせるスキル
- [ ] 応募先ごとに志望動機を書き分ける
- [ ] LinkedIn・転職サイトのプロフィールも同じ内容でそろえる（スカウト経由の応募が多い業界）

## 3. 業界の知識（2〜4週目・並行）

### SaaS（面接で普通に出てくる言葉）
- [ ] MRR／ARR（月・年で積み上がる売上）、チャーン（解約率）、LTV、CAC
- [ ] 分業型の営業：マーケ → IS → FS → CS（「The Model」型）
- [ ] 受けたい会社のサービスを実際に触る（無料トライアル・デモ動画）
- [ ] 自分の経験との共通点を見つけておく：整体院の事業計画も「月額制・解約されない仕組み・リピート」で、SaaSと同じ考え方をしている → 志望動機の材料になる

### コンサル（選考が独特なので対策必須）
- [ ] **ケース面接**：「〇〇の売上を上げるには？」をその場で考えて話す練習
- [ ] **フェルミ推定**：「日本に整体院は何軒ある？」のような概算の練習
- [ ] 筆記・Webテスト（SPI・玉手箱など）の対策本を1冊
- [ ] ロジカルシンキングの基本（結論から話す、MECE）

## 4. 応募の窓口（2週目〜）

- [ ] 転職エージェントに**2〜3社**登録（大手の総合型1社＋SaaSやコンサルに強い特化型1〜2社）
- [ ] スカウト型の転職サイトに職務経歴書を載せる
- [ ] エージェントに必ず聞く：在宅の実態、副業可否、未経験からの採用実績、選考で落ちやすいポイント
- [ ] 応募は同時に5〜10社。本命は面接に慣れた後半に回す

## 5. 面接対策（3週目〜）

- [ ] よく聞かれる質問への答えを準備：自己紹介（1分）、転職理由、志望動機、実績、失敗とそこからの学び、5年後
- [ ] 逆質問を3つずつ用意（例：「入社後3か月で期待される成果は？」「ISからFS・CSへの異動はありますか？」）
- [ ] 声に出して練習 → 録音して聞き直す
- [ ] オンライン面接の環境：カメラの高さ、明るさ、背景、マイク

## 6. お金と手続き

- [ ] **在職中に転職活動する**（収入を止めない）
- [ ] 生活費3か月分の目安を把握
- [ ] 内定後：条件（年収・在宅・副業規定）を**書面で**確認してから退職を申し出る
- [ ] 退職時：有給の消化、健康保険・年金の切り替え、源泉徴収票の受け取り
- [ ] 整体院の事業を続ける場合：転職先の副業規定を確認。開業届を出しているなら、それも伝え方を整理しておく
