# LINE予約・リピート配信シナリオ（岩井整体院・見本）

商談の「3. デモ」で見せる中身。事業計画 p.5「来店翌日のお礼と1か月後の案内が自動で届くLINE」を具体化したもの。
実店舗に導入するときは、院長ヒアリングで【】の部分を差し替える。

---

## 1. 全体の流れ

| タイミング | 配信 | 目的 |
|---|---|---|
| 友だち追加直後 | あいさつ＋初回の流れ | 予約のハードルを下げる |
| 予約前日 18:00 | リマインド | 無断キャンセル防止 |
| 来店翌日 12:00 | お礼＋自宅ストレッチ | 「覚えてもらえている」安心感 |
| 来店7日後 | 調子うかがい（返信しやすい質問） | 双方向のやりとりをつくる |
| 来店30日後（次回予約なしの人のみ） | 再来店のご案内 | **2回目の来店を増やす（本丸）** |
| 来店60日後（次回予約なしの人のみ） | 軽いお知らせ | 休眠防止。押し売りしない |
| 月2〜4回（全員） | 季節のセルフケア・空き枠情報 | 思い出してもらう |

> ツール：LINE公式アカウント（無料プランは月200通まで）＋予約・ステップ配信の拡張ツール（Lステップ、エルメ等）。来店日を起点にした配信には拡張ツールが必要。月の通数と料金プランは導入前に最新情報を確認する。

## 2. 配信文面

### ① 友だち追加直後
```
【岩井整体院】です。友だち追加ありがとうございます。

このLINEでできること
・空き枠の確認とご予約（24時間）
・予約の変更・キャンセル
・ご質問（施術中は返信が遅れることがあります）

はじめての方は約60分（6,000円）です。
下のメニューの「予約する」からどうぞ。
```

### ② 予約前日 18:00
```
【お名前】様
明日【時刻】にご予約をいただいています。

・動きやすい服装でお越しください（着替えもあります）
・変更やキャンセルは、このLINEで返信いただければ大丈夫です

お会いできるのを楽しみにしています。
```

### ③ 来店翌日 12:00
```
【お名前】様、昨日はご来院ありがとうございました。

お伝えしたストレッチの動画をお送りします。
1日1回、お風呂上がりがおすすめです。
▶【動画リンク】

もし気になることがあれば、いつでもこのLINEにどうぞ。
```

### ④ 来店7日後
```
【お名前】様、施術から1週間たちましたが、その後いかがですか？

よければ、下から近いものを選んでください。
[変わらず過ごせている] [少し気になる] [ストレッチの質問がある]
```
※ボタン回答でタグ付けし、「少し気になる」の人には院長が個別に返信する。

### ⑤ 来店30日後（次回予約なしの人だけ）
```
【お名前】様、前回のご来院から1か月がたちました。

デスクワークが続くと、このころに肩まわりが重く感じる方が多いです。
ご都合がよければ、空いている枠からどうぞ。
▶【予約リンク】

もちろん、ストレッチだけ続けていただくのも大歓迎です。
```

### ⑥ 来店60日後（次回予約なしの人だけ）
```
【お名前】様、お変わりありませんか。
今月は【曜日・時間帯】に比較的空きがあります。
また必要なときに思い出していただければうれしいです。
```
※60日後以降は自動配信を止め、月数回の一斉配信のみにする（しつこくしない）。

## 3. 書くときのルール（コンプライアンス）

- **効果を断定しない**：整体は医療ではない。「治る」「改善します」「〇回で良くなる」は使わない（医師法・あはき法・景品表示法の観点）。「〜が気になる方へ」「多くの方が〜と感じる時期」の表現に留める。
- **整骨院（柔道整復師）の場合**は広告できる事項がさらに限られる。整骨院の案件は院長に既存の掲載内容を確認してから文面を作る。
- **口コミは操作しない**：「口コミを書いたら割引」はNG（ステマ規制・Googleのポリシー違反）。お願いするなら「よければ感想をお聞かせください」まで。
- **お客様の声**は本人の同意を得た実際の声だけを使う。
- **配信を止める方法**（ブロック・配信停止）を妨げない。

## 4. 毎月の報告で出す数字（月次レポートのもと）

| 指標 | 見方 |
|---|---|
| 友だち数（増減） | 院内POP・HPからの流入が機能しているか |
| LINE経由の予約数 | 電話予約からの置き換えが進んでいるか |
| 30日配信 → 予約した人数 | **リピートの仕組みが効いているかの中心指標** |
| 2回目来店率（初回客のうち60日以内に再来店した割合） | 導入前と比べる。導入前の数字は初回ヒアリングで必ず聞いておく |
| ブロック率 | 5%を超えたら配信頻度・内容を見直す |
