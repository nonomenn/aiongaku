# 楽曲設計：帰り道

- BPM：72
- Key：F Major（やわらかく、切なさも出る長調。G Majorより落ち着いた温度感）
- 拍子：4/4
- 全体尺（目安）：約3分50秒

## コード進行の方向性
- Aメロ：F → Em7(♭5)代替で Am7 → Dm7 → B♭ → C（静かに流れる、王道進行寄りだが起伏を抑えた形）
- Bメロ：Dm7 → C/E → B♭ → C（サブドミナントからの浮遊感でざわつきを表現、サビへ向け緊張を溜める）
- サビ：F → C/E → Dm7 → B♭ → F/A → Gm7 → B♭ → C（カノン進行を軸に少し変形、切なさと前進感を両立）
- ラスサビ：同進行を半音～全音転調（F→G Major）し、さらにB♭セクションで一瞬サブドミナントマイナー（B♭m）を挟み、「言えた」瞬間の感情の揺らぎと景色の変化を演出

## 構成
Intro（0:00-0:12）→ Verse1（0:12-0:40）→ Pre-Chorus（0:40-1:00）→ Chorus（1:00-1:30）
→ Verse2（1:30-1:55）→ Pre-Chorus2（1:55-2:15）→ Bridge（2:15-2:45）
→ Last Chorus（2:45-3:30）→ Outro（3:30-3:50）

## 楽器・アレンジ
- 主軸楽器：アコースティックギター（アルペジオ中心）、ピアノ（和音の補強、Bメロ以降に薄く追加）
- その他質感：遠くの踏切音（Intro/Outroのみ、環境音として）、弱いパーカッション（ブラシ系、サビから）
- サビでの追加要素：ストリングス（控えめなパッド、感情を押し広げる程度）、ベースが初めて明確なラインを持つ
- ラスサビでの追加要素：転調＋ストリングスが主旋律に寄り添う形に厚みを増す、ピアノが高音域でオクターブ上の装飾フレーズ、アコギのストロークが増えて推進力を出す（ただし音圧は抑え、余韻を残す）

## ボーカル
- 声質・性別・トーン：女性ボーカル、10代後半〜20代前半を感じさせる等身大の声。作り込みすぎない、少し息の混じったナチュラルなトーン。
- 歌い方の指示：
  - Aメロは会話するように、抑揚を抑えて語りかける歌唱
  - Bメロで徐々に息遣いに焦りと揺らぎを足す
  - サビは張り上げすぎず、「願うように」歌う。言葉の語尾を伸ばしすぎない
  - ラスサビの「明日も、一緒に帰ろう」の一節だけ、わずかに声を強めて感情の踏み出しを表現。直後の最終行「でも今日は、ちゃんと言えた」は囁くように、余韻を残して着地

## 盛り上がり設計
- サビ：Bメロからの緊張を解放する形で開くが、音量・楽器数は抑えめにスタートし、2回目のリフレイン（「あと十分だけ」）でストリングスとベースが入り膨らむ2段階構成
- 転調の有無：あり。ラスサビ直前（Bridge終盤）でF→Gへ全音転調。景色が変わる瞬間として「言えた」瞬間と転調のタイミングを一致させる
- ラスサビ：転調＋楽器増加に加え、「また明日」→「明日も、一緒に帰ろう」の対比部分でブレイク（一瞬楽器を薄くする）を入れてから一気に厚みを戻す。ラスト2行（「あと十分だけ〜」「でも今日は〜」）はアコギとボーカルのみに絞り、Outroの踏切音へ静かに繋げる
